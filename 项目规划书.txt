一、 项目定位与选题背景
* 项目名称：VibeTrends AI: AIGC与就业冲击及跨界编程(Vibe Coding)趋势诊断平台
* 目标用户：劳动力市场研究学者、科技新闻记者、面临转型求职的学生及独立开发者。
* 核心立意：
AIGC 的兴起使高度重复性工作面临自动化替代风险（Layoff Risk）。与此同时，以 AI 协同（Cursor, Claude）为代表的 Vibe Coding 浪潮降低了零代码背景人群的开发门槛。本平台通过数据过滤、AI 动态绘图与智能体交互，深度诊断这一职场变革趋势。

二、 [已实现] 可选分析模组：解决用户冷启动痛点
Tab 1 顶部内置四张 CSS 卡片式按钮（一键执行），用户无需输入，点击即触发 LLM 生成 Plotly 图表：
   1. Automation vs Layoff Risk (Impact Model)
      -> Routine_Task_Percentage + Tasks_Automated_Percentage vs Layoff_Risk
   2. Creativity & Human Interaction (Safe Haven Model)
      -> Creativity_Requirement + Human_Interaction_Level 作为就业护城河
   3. AI Learning & Adaptability (Transition Curve)
      -> Education_Level vs AI_Usage_Hours_Per_Week + AI_Training_Hours
   4. AI Tools & Experience Gap (Tech Generation Divide)
      -> Age + Years_of_Experience vs Number_of_AI_Tools_Used

六、 核心功能运作流程说明
1. 动态 Plotly 绘图引擎流程 (Tab 1)
[ 用户点击一键卡片 或 输入自定义 query ]
    -> PromptManager 拼接数据集 Schema
    -> ChatGateway 向 LLM 请求生成 Python 代码
    -> 覆写 dynamic.py -> importlib.reload(dynamic) 热加载
    -> Streamlit 渲染 Plotly 交互式图表

2. AI Agent 工作流 (Tab 2)
[ 用户输入问题 ]
    -> st.status() 展开思考链
       - Stage 1: Thought（意图识别：计算/舆情/咨询）
       - Stage 2: Action（路由调用 stats_analytics / data_fetcher）
       - Stage 3: Observation（工具返回硬数据）
       - Stage 4: LLM 基于硬数据生成最终回复
    -> 带数据支撑的分析报告

3. 多源数据爬虫工作机制（v2.0 增强版）
[ Agent 判断为舆情类问题 ]
    -> v2ex_crawler.MultiSourceCrawler.search_all(keyword)
       - 并行查询 V2EX（requests + bs4）+ Hacker News（Algolia REST API）
       - V2EX 优先搜索 /search?q=，无结果回退 /go/programmer 节点
       - HN 无需 API Key，直接调用 hn.algolia.com/api/v1/search
       - 结果合并去重（基于标题相似度）
    -> DataPersistence.save() 自动追加到 crawled_data.csv
    -> 格式化输出 -> 结果返回 Agent -> LLM 润色
    -> 全部网络失败则自动降级 Mock 数据

七、 数据集详细信息
* 数据源：Kaggle AI Impact on Jobs and Layoff Risk Dataset
* 规模：20,000 条员工记录，16 个维度
* 8 个行业：Education, Finance, Healthcare, IT, Logistics, Manufacturing, Retail, Telecom
* 24 个岗位：Software Engineer, Data Analyst, Accountant, Nurse 等
* 4 个学历等级：High School, Bachelor's, Master's, PhD
* 3 个公司规模：Small, Medium, Large
* 失业风险分布：High 6797 / Medium 6601 / Low 6602（近似均匀）
* 数据完整性：全部 16 列零空值，无需预处理
